What is Python?

Python is a programming language known for reading almost like plain English. It's a great first language because you spend less time dealing with punctuation and more time solving problems.

1. Printing something to the screen

The print() function shows text on the screen. Whatever you put inside the parentheses gets displayed.

print("Hello, world!")
Hello, world!

2. Storing values in variables

A variable is a named box that holds a value. You create one just by giving it a name and a value with =.

name = "Clark" age = 20 print("Hi, I'm", name, "and I'm", age, "years old")
Hi, I'm Clark and I'm 20 years old

3. Making decisions with if

An if statement runs code only when a condition is true.

age = 16 if age >= 13: print("You're a teenager.") else: print("Not a teenager yet.")
You're a teenager.

4. Repeating with a loop

A for loop repeats a block of code once for every item in a list.

subjects = ["math", "art", "coding"] for subject in subjects: print("I'm learning", subject)
I'm learning mathI'm learning artI'm learning coding

5. Doing math

Python can do arithmetic like a calculator. Use + to add and - to subtract.

allowance = 1000 spent = 599 left = allowance - spent print("I have", left, "pesos left")
I have 401 pesos left
